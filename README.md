# MediVital und Klinik Solequelle – Rechner zur betrieblichen Altersvorsorge

Online-Rechner zur betrieblichen Altersvorsorge für die Mitarbeitenden des MediVital Therapiezentrums und der Klinik Solequelle (QR-Code in der E-Mail-Information).

- Rechner: https://olibau.github.io/bav-dashboard-medivital-solequelle/ (Kurz-URL: https://tinyurl.com/medivital-solequelle-rechner)

Der Rechner läuft vollständig im Browser – es werden keine Daten gespeichert oder übertragen.
